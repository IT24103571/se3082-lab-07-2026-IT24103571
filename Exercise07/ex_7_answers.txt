3. THINKING QUESTION

When would you choose Scan instead of Allreduce?

MPI_Scan should be used when each process needs a cumulative result
based on itself and all processes before it.

For example, MPI_Scan can be used to calculate global offsets,
running totals, cumulative distributions, or global index positions.

MPI_Allreduce should be used when every process needs the same final
global result.

Therefore:

- MPI_Scan -> Each process gets its own cumulative result.
- MPI_Allreduce -> Every process gets the same final result.
